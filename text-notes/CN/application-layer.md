# 应用层

客户服务器方式C/S, client/server与对等方式P2P,peer-to-peer

动态主机配置DHCP

	使用传输层UDP协议
	报文类型如下：
		DHCP DISCOVER 	发现报文
		DHCP OFFER 		提供报文
		DHCP REQUEST 	请求报文
		DHCP ACK 		确认报文
		DHCP NACK		否认报文
		DHCP RELEASE	释放报文
	在从DHCP服务器获得可用IP地址前，客户机需要使用0.0.0.0来发送各DHCP报文，服务器使用255.255.255.255作为目的IP来广播回复
	通常不会给每一个网络配置单独的DHCP服务器，而是使用至少一个DHCP中继代理

域名系统DNS

	域名层次 如：*.三级域名.二级域名.一级域名
	域名服务器层次
		根域名服务器 记录所属的顶级域名的顶级域名服务器IP，
		顶级域名服务器 管理在该顶级域名服务器注册的所有二级域名，
		权限域名服务器 管理某个区的域名
		本地域名服务器 起代理的作用，将查询报文转发到上述的域名服务器层次结构中

文件传送FTP

	主动方式 由服务器主动发送TCP连接请求并携带使用的端口号，主动方式下使用20号端口传输数据
	被动方式 由客户端主动建立连接，服务端被动等待连接建立和数据传输请求，被动方式下使用的端口号由双方协商

电子邮件

	电子邮件系统的组成结构
		客户机本地的用户代理
		邮件服务器
		基于万维网的电子邮件 通过网站使用邮件服务，不再需要SMTP和POP3，而是HTTP

	电子邮件格式与MIME
		分为信封和内容，内容由首部和主体构成
		MIME SMTP只能传送ASCII码文本，非ASCII码传输需要MIME进行转换，MIME，多用途因特网邮件扩展

	SMTP协议与POP3
		SMTP用于客户端和服务器，服务器与服务器之间的电子邮件发送，客户端读取服务器上的邮件使用POP3，post-office-protocol 邮局协议，此外还有IMAP因特网邮件访问协议，用户可以在自己的计算机上操作服务器中的邮件，可以看出IMAP是一个联机协议
		SMTP和POP3都基于TCP连接，SMTP使用25号端口，POP3使用110号端口，IMAP使用143号端口

	WWW 的概念与组成结构
