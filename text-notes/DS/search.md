# 查找算法要点

## 线性表查找

1. 顺序查找
	- 常见设置0号位为哨兵位，将待查找元素放置在哨兵位，如果使用从索引大到小的方向匹配，则循环结束后判断匹配位下标是否为0表示是否查找成功

2. 折半查找

3. 分块查找，或称索引顺序查找
	- 块内无序，块间有序

## 树状查找

### 二叉搜索树

- 按中序遍历可以得到有序序列
- 平均查找长度O(log2 n)级别
- 最差情况退化为有序链表，查找长度O(n)级别

### 平衡二叉树

#### 基本性质

节点中需要额外数据域存储保持平衡的信息
1. 平衡因子，等于左子树高减右子树高，取值只有-1、0、1，绝对值超过1表示不平衡
2. 左右子树的树高，取更大者
> 使用第二种表示方法时需动态计算其平衡因子

### 红黑树

### B/B+树

#### 基本性质

设有n阶B树(或称B-树)
- 数据分散地存储在各个节点中，按中序遍历可得到关键字大小有序的序列，元素之间的间隔对应一个分支
- 根节点至少有`2`个分支，则至少`1`个元素
- 非根节点至少有`n/2`个分支(n为奇数则上取整)，则至少`(n/2)-1`个元素
- 节点最多有`n`个分支，`n-1`个元素

```
    // B树中单个节点的分支
    { [elem] [elem] [elem] [elem] }
     /      |      |      |      \
    {}      {}     {}     {}     {}

```
<br/>

对于n阶B+树
- 非叶节点不存数据，只存关键字索引，所有数据保存在叶节点中，每个元素对应一个分支
- 节点的分支数量下限与B树一致，但是元素数量与分支数量相等
- 节点最多`n`个分支，`n`个元素

```
    // B+树中单个节点的分支
    { [elem] [elem] [elem] [elem] [elem] }
        /      |      |      |      \
       {}      {}     {}     {}     {}

```
