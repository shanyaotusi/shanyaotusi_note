# 指令

---

## 指令格式

指令格式包含操作类型和操作数

```
  | 操作码 | 地址码 |
```

### 变长指令和定长指令

指令分为变长指令和定长指令格式

- 变长指令集可以将常用的指令长度做的较短，不常用的指令长度较大，可以高效利用存储空间，但是硬件实现较复杂，例如Intel X86系列

- 定长指令同一指令的长度，可以降低硬件成本，利于指令顺序寻址、取指和译码，但是浪费存储空间，例如MIPS系列

指令的字长是字节的整数倍，因此不论是变长指令或定长指令，长度都是字节整数倍，指令长度一般有以下几类：

1. 半字长指令 每次访存取可以两个指令

2. 单字长指令 每次访存取一个指令

3. 多字长指令 每次取一个指令需要多次访存

### 操作码

指出操作类型，比如加减运算

操作码有定长操作码和变长操作码之分，不过与定长指令与变长指令不是一个概念

### 地址码

指出具体操作数，可能是具体数字也可能是数据的内存地址或寄存器编号等，并且可能包含**多个操作数**

```
// 三地址指令格式

  | 操作码 | 源操作数1 | 源操作数2 | 目的操作数 |

// 二地址指令格式

  | 操作码 | 源操作数1 | 源操作数2 |
		  | 目的操作数 |

// 单地址指令格式

  | 操作码 | 源操作数 |
		  | 目的操作数 |

// 零指令格式

  | 操作码 |

```

## 指令的寻址方式

### 顺序寻址

内存中指令按顺序存放，CPU按顺序取指令并执行，每次取到指令后将程序计数寄存器PC的值自动加一（指令长度），指向下一指令

> PC的值一般不是加一，而是加上指令长度，从而指向下一指令，计算机一般按字节编址，而指令长度当然不止一个字节

### 跳跃寻址

- 分支指令 基于条件跳转指令的地址

- 跳转指令 无条件跳转指令地址

## 操作数的寻址方式

种类较多，如下

- **立即寻址** 直接在地址字段给出操作数，这种操作数称为立即数

- **直接寻址** 地址字段的值是操作数的有效地址

> 如果使用虚拟存储系统，那么有效地址就是虚拟地址，如果不使用虚拟地址，那么有效地址是物理地址

- **寄存器寻址** 也称寄存器直接寻址，地址字段给出寄存器编号，操作数存放在该寄存器中

- **寄存器间接寻址** 给出的寄存器中存放操作数的有效地址，需要根据有效地址获取操作数

- **变址寻址** 常用于数组元素的访问，地址字段给出基准地址，地址偏移量由*变址寄存器*给出，相当于元素下标

- **基址寻址** 地址字段给出偏移量，基准地址由其他寄存器给出，常用于多道程序执行

- **相对寻址** 地址字段给出偏移量，基准地址由PC隐含地给出，意味着操作数位于指令的前后某个固定位置上，常用于转移指令

## 指令类型

1. 数据传送指令

2. 算术与逻辑运算指令

3. 移位操作指令

4. 程序控制指令

5. 输入输出指令

6. 其他

## 复杂指令集计算机和精简指令集计算机

### 复杂指令集计算机 CISC 

complex instruction set computer

常见Intel系列

- 提供多种指令，硬件实现复杂
- 指令格式和长度差别大，指令执行时间相差大
- 软件向后兼容
- 大多使用微程序控制器，多数指令需要多个时钟周期完成

### 精简指令集计算机 RSIC

reduced instruction set computer

- 减少了不常用的指令，只使用频度高的简单指令
- 指令长度一致，格式少，寻址方式简单
- 使用流水线方式执行指令，多数指令可以在一个时钟周期内完成
- 使用硬连线控制器，较少采用或不使用微指令
- 使用大量通用寄存器，减少访存次数
