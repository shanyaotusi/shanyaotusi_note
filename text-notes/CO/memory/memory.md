## 静/动态随机存储器

### 存储元

1. 6mos 存储元，用于静态随机存储器 SRAM
    - 行列地址线同时给出
    - 读取操作不影响存储数据
2. 单mos加电容 存储元，用于动态随机存储器 DRAM
    - 行列地址线不需要同时给出，因此常复用地址线分别选中行地址和列地址
    - 读取数据是破坏性的，因此读取后需要重新写入
        - 每列含一个*灵敏读出/恢复放大器*，数据读出时会记录该列电平变化，并在读取数据后重新写入
        - 输出时输出灵敏读出/恢复放大器记录的电平

### 动态刷新

由于动态随机存储器使用电容存储，随时间会流式电平，因此需要周期性刷新存储器

**最大刷新周期** 即存入数据后到数据流失的时间，超过这段时间会丢失数据

**刷新周期** 即存储器实际刷新的时间，在该时间段内完成所有存储元的刷新

#### 刷新方式

DRAM是**按行刷新**的，减少行数可以减少刷新周期

- 将刷新周期等间隔划分为多个时隙（存取周期）

1. **集中刷新** 在一段连续的时隙内完成刷新，刷新时CPU将无法访问存储器，这段时间称为死区时间

2. **分散刷新** 每一次存取跟一个刷新操作的时间作为新的存取周期，因此不存在死区时间，但是一个刷新周期内进行了多次完整的刷新，浪费较多

3. **异步刷新** 在一次刷新周期内只完整刷新一次

## 存储器的扩展

### 位扩展

当CPU位宽大于存储器的位宽时，进行位扩展

- 将多个存储芯片并联，这样地址线同时选中多个芯片，数据线同时读写多个芯片
- 如果芯片是一位的，那么单一数据的不同位将被存储在不同的芯片上

### 字扩展

当CPU寻址空间大于存储器容量时进行字扩张

- 地址线的高位经过译码器后作为片选信号，选择不同的存储芯片工作

> 此外还有同时使用位扩展和字扩展的**字位同时扩展**

## 主存系统优化

### 单体多字存储

- 与位扩展的方法一致，同时读入多个存储模块的数据，以此提高数据带宽

> 单体多字存储是多通道存储技术的原理

### 多体交叉存储

与字扩展的方法一致

- **高位多体交叉** 使用地址的高位作为片选信号，由于程序局部性的特点，会导致同一芯片模块被频繁访问

- **低位多体交叉** 使用地址低位作为片选信号
