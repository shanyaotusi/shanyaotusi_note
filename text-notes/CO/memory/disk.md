## 磁盘阵列RAID 
Redundant Array of Independent Disks ，采用独立磁盘构成具有冗余能力的阵列，就是多个独立磁盘组合形成一个大的磁盘系统，实现比单块磁盘更好的存储性能和更高的可靠性

- RAID0 简单的、无数据校验的磁盘阵列，并不提供冗余策略，将磁盘交叉存放，读写时可以并行，提高存取速度

- RATD1 镜像存储磁盘阵列，单位成本最高，读写时无差别读写到两份磁盘，即工作磁盘和镜像磁盘

- RAID2 使用海明码检错和恢复数据

- RAID3 **位**奇偶效验码，只能检错

- RAID4 **块**奇偶效验码，以块为单位

- RAID5 **分布式**奇偶效验码
