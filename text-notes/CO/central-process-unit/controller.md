# 控制器（控制单元）

---

## 指令周期

1. **取指周期** 
    主要涉及四个寄存器，完成以下操作
    1. PC -> MAR
    2. 向主存发送读命令 1 -> R
    3. 主存取指令 M(MAR) -> MDR 
    4. MDR -> IR
    5. 指令送控制器译码 IR -> CU 
    6. (PC)+1 -> PC

2. **间址周期**
    主要完成取操作数有效地址的任务，有的指令没有间址周期
    1. IR中的操作码地址（形式地址） Ad(IR) -> MAR
    2. 向主存发送读命令 1 -> R
    3. 主存取有效地址 M(MAR) -> MDR 
    4. 将有效地址送至指令寄存器的地址字段 MDR -> Ad(IR)
        > 有些机器中省略这一步

3. **执行周期**
    不同指令有不同的微操作，常见非访存指令、访存指令和转移指令

4. **中断周期**
    执行周期结束后，CPU需要检查是否有请求中断事件发生，若有则进入中断周期，以断点存入主存特定单元，使用硬件向量法为例，需完成如下操作
    1. 将PC内容（程序断点）保存到主存指定单元
    2. 将中断向量地址形成部件的输出送至PC
    3. 关中断，该操作可由硬件自动完成

## 硬连线控制器

也称有限状态机控制器或组合逻辑控制器或PLA控制器，由复杂的逻辑电路在时钟信号驱动下得出微操作控制信号

## 微程序控制器

使用微程序方式实现的控制器，主要思想如下

- 将每条指令的执行过程用一个**微程序**表示
- 每个微程序由若干**微指令**组成，相当于有限状态机中的一个状态
- 微程序存放在ROM中，称为**控制器存储器**，是微程序控制单元的核心部件

### 控制存储器中的微程序结构

- 微指令的基本结构

    ```
      | 操作控制 | 顺序控制 |
    ```

    - 操作控制字段用来发出控制信号，字段中为`1`的位将发出控制信号

    - 顺序控制字段指出下一微指令地址（下地址）
    > 下面的例子中该字段就是下地址，但是顺序控制字段不一定直接给出下地址，更多方式见[顺序控制方式](#顺序控制)

<br/>

- 控制存储器中微程序基本结构

    ```
    控制存储器
        M   [           | M+1 ] 取指周期微程序
        M+1 [           | M+2 ] 
        M+2 [           | xxx ]
            [       ...       ]
            [           | N+1 ] 间址周期微程序
            [           | N+2 ] 
            [ 转执行周期微程序 ]
            [       ...       ] 中断周期微程序
            [ 转取指周期周期微程序 ]
        Q   [           | Q+1 ] ADD指令微程序
        Q+1 [           | Q+2 ] 
        Q+2 [           |  M  ]
        P   [           | P+1 ] ADD指令微程序
        P+1 [           | P+2 ] 
        P+2 [           |  M  ]
            [       ...       ]

    ```

### 执行过程

- 用户程序首地址送至PC
- 取指阶段
    - 顺序执行*取指周期微程序*，执行后指令被存到IR中
- 执行阶段
    - 指令中的**操作码字段**被送至微地址形成部件，该部件输出对应微程序的首地址
    - 首地址被送至CMAR（控制存储器地址寄存器）随后执行对应的微程序
    - 执行到最后一条指令后跳转到`M`地址，即进入下一指令的取指周期

### 微指令的编码

- 直接编码方式

    - 这种方式中微指令的不同位即直接对应一个微操作，某一位为`1`即表示打开某一控制门，为`0`即表示关闭该控制门
    - 但是这种方式的控制字段位数较多，对控存的容量要求极高
<br/>

- 字段直接编码方式

    - 将控制字段分为若干段，互斥的命令放在同一段内
    > *互斥的命令不会同时出现，所以将其放在同一字段内*
    - 对不同字段进行译码得到对应的每一个微命令，又称为显式编码
    > 例如，三位的字段可表示7个互斥的微命令，留出一位表示不发出微命令，由此节省了微指令四位，但是需增加译码电路，增加了执行时延
<br/>

- 字段间接编码方式
    - 字段的译码结果受到其他字段译码输出的影响，由称为隐式编码
    - 虽然可以进一步减少微指令字长，但是降低了并行控制能力，一般作为字段直接编码方式的辅助手段

- 混合编码方式
    - 直接编码和字段编码方式混合使用

- 其他

### 顺序控制的方式

大致有两种方式

1. 断定法 即顺序控制字段直接给出下地址

2. 根据操作码形成
    - 可使用PROM实现，操作码字段直接作为PROM地址，存储单元的内容即为对应微程序首地址
<br/>

其他方式

3. 增量计数法 对于顺序地址，使用CMAR自增`1`的方式得到下一微指令地址

4. 分支转移 遇到条件转移指令时，微指令出现分支，此时需要根据各种标志得到下一微指令地址，其微指令格式如下

    ```
    | 操作控制字段 | 转移方式 | 转移地址 |
    ```

    - 转移方式指出判别条件
    - 转移地址指出判别成功后的转移地址，不成功则顺序执行
    - 有的转移微指令指出两个转移地址，成功或失败对应不同转移地址

5. 由硬件产生 
    - 机器上电后，第一条微指令可由专用硬件电路产生，也可由外界直接向CMAR给出，
    - 当中断请求出现后，可由硬件产生中断微程序的入口地址
    - 出现间址寻址时，也可由硬件产生间址周期微程序的入口地址

### 微指令格式

通常分为两种

1. **水平型微指令**

    其特点是一次定义并执行多个并行操作的微命令，如前面介绍的[直接编码、字段编码和混合编码方式](#微指令的编码)

2. **垂直型微指令**

    特点是采用类似机器指令操作码的方式，操作码字段规定微指令的功能，其格式如下

    ```
      | 操作码 | 地址码 | 其他控制字段 |
    ```

    - 地址码可用于指出操作的寄存器或存储器，也可能是微指令的分支指令的目的地址

    - 其他字段指出控制方式，如移位方式、指出分支指令测试条件、读写命令等

- 水平型指令更为灵活，效率高且并行能力强
- 水平型指令的格式与机器指令差别大，垂直型指令则与机器指令相似
- 水平型指令执行一条机器指令的微指令数量少，速度块，垂直型指令则较多，因而速度较慢
- 水平型微指令的指令字长较长，微程序较短，垂直型则相反
