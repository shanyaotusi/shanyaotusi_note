# 计算机系统概述

## 系统结构

### 抽象层转化

- 用户
    - 应用程序
- 程序员
    - 算法
    - 编程语言
    - 操作系统/虚拟机
- 架构师 
    - 指令集体系结构（*ISA*，*Instruction-Set-Architecture*）
    - 微体系结构
    - 功能部件
- 电子工程师
    - 电路
    - 器件
```

    - 应用程序    -----------
    - 算法               |
    - 编程语言          软件
    - 操作系统/虚拟机     |
    - 指令集体系结构---------
    - 微体系结构         |
    - 功能部件         硬件
    - 电路              |
    - 器件    --------------
```

#### 编程语言

- 低级语言
    与机器结构密切相关    
    - 机器语言，即二进制编码的机器指令
    - 汇编语言，为了方便记忆和读写的英文符号，和机器语言/指令一一对应
- 高级语言
    与底层计算机结构无关

#### 编程语言处理

- 汇编程序或汇编器
    将汇编语言源程序转换为机器语言目标程序
- 解释程序或解释器
    将源程序的语句按执行顺序逐条翻译为机器语言**并立即执行**
- 编译程序或编译器
    将高级语言源程序翻译为汇编或机器语言目标程序

#### ISA指令集体系结构

软件和硬件之间的接口，主要包含如下规定内容

- 可执行的所有指令集合
    - 操作数存放的位置、类型
    - 指令格式
    - 指令操作类型
    - 指令操作数类型
- 寻址方式
- 可访问地址空间大小
- 程序可访问寄存器的个数、位数和编号
- 控制寄存器的定义
- IO空间编址方式([*见IO部分的内存映像*](../OS/io-manage/io.md/#io设备与设备控制器))
- 中断结构
- 机器工作状态定义和切换
- 输入输出结构
- 数据传输方式
- 存储保护方式
...

#### 微体系结构

- 指ISA的具体实现组织，简称*微架构*，由逻辑电路组成，主要指硬件的实现方式如加法器是串位进位或并行进位等
- 对于相同的ISA可能有不同的实现微架构

## 冯.诺依曼计算机体系

- 以存储器为核心的计算机结构，核心思想如下
    - 使用**存储程序**的工作方式
    - 计算机由五个基本部件组成
        - **存储器**存放数据和指令
            - 数据和指令在存储形式上没有不同，计算机应自行区分
        - **控制器**控制指令的自动执行
        - **运算器**应能进行基本的四种运算和逻辑运算
        - **I/O设备**允许操作人员使用计算机
    - 以二进制表示数据和指令
        - 指令由操作码和地址码组成，操作码指明操作类型，地址码指出操作数的地址
